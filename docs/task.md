Производительность обучения
Чтобы сравнить производительность разных моделей, нужно дообучить их на одинаковых датасетах и замерить затраченное время.
В качестве датасета возьмём CIFAR, так как в нём достаточно изображений для достоверной оценки как производительности, так и точности, что тоже нам понадобится.
Каждая модель — это целое семейство архитектур. Для сравнения подберём их версии, примерно равные по количеству параметров:
"microsoft/cvt-21" — 31 миллион параметров (ближайшая опция, средняя модель в семействе),
"microsoft/swin-base-patch4-window7-224" — 87 миллионов параметров,
"google/vit-base-patch16-224-in21k" — 86 миллионов параметров,
Все подобранные архитектуры рассчитаны на изображения размера 224×224px, предобучены на одном и том же датасете ImageNet.
Удобно, что эти модели можно загрузить с помощью универсальных классов AutoImageProcessor, AutoModelForImageClassification из библиотеки transformers. В коде это выглядит так:

from transformers import AutoImageProcessor, AutoModelForImageClassification

model_name = "microsoft/cvt-21" 
processor = AutoImageProcessor.from_pretrained(model_name)
model = AutoModelForImageClassification.from_pretrained(model_name) 
В прошлых уроках вы уже дообучали и ViT, и гибридные трансформеры зрения, поэтому для сравнения производительности сразу перейдём к практическому заданию.
Задание 1
Чтобы выполнить это задание, подключитесь к виртуальной машине. Обучение выполняйте на GPU.
Дообучите на датасете CIFAR три модели:
"microsoft/cvt-21",
"microsoft/swin-base-patch4-window7-224",
"google/vit-base-patch16-224-in21k".
Измерьте время дообучения каждой из них.
Для этого:
Напишите универсальный код, подходящий для загрузки любой из трёх моделей. Используйте классы AutoImageProcessor, AutoModelForImageClassification из библиотеки transformers.
Напишите код для загрузки датасета torchvision.datasets.CIFAR10, подготовьте обучающую, тестовую и валидационную части.
Напишите полноценный код для дообучения загруженной модели на классах датасета CIFAR.
Замерьте время дообучения модели в течение 1 эпохи (например, с помощью библиотеки time).
Сохраните дообученную модель для следующего задания.
Повторите процедуру обучения три раза — отдельно для каждой модели — и запишите результаты временных замеров.
Выполните задание на ВМ, полученной в предыдущем уроке. Затем сверьтесь с авторским решением и ожидаемым результатом.
